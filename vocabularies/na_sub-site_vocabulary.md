# NATURAL AREAS PROJECT — SUB‑SITE VOCABULARY MODULE v1
Authoritative, versioned, single‑source‑of‑truth controlled vocabularies for all Sub‑Site–level fields in the statewide Natural Areas & Trails system.

This module contains:
- All controlled vocabularies used in the Sub‑Site Schema v1  
- Rules for each controlled vocabulary  

All Sub‑Site–related modules must reference this module for vocabulary authority.

---

# 1. SUB‑SITE CATEGORY VOCABULARY (Controlled)

## Allowed Values
Garden  
Memorial  
Historic Structure  
Historic Feature  
Cultural Feature  
Natural Feature  
Facility  
Recreation Feature  
Overlook  
Water Access Feature  
Trail Feature  
Other (explicitly named only)

## Rules
- Category expresses the ontological identity of the Sub‑Site.  
- Must not duplicate Site Categories.  
- Must not represent Trails, Trail Segments, or Access Points.  
- “Other” may be used only when explicitly named in authoritative sources.
